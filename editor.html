Publishing changes

1. Edit fields above and click Download updated content.js.

2. Replace the old content.js in your website folder with the downloaded file.

3. To add photos, copy image files into the images folder and type paths such as images/portrait.jpg in the photo fields. Download content.js again after changing photo paths.

4. Upload the updated content.js to your GitHub Pages repository. Keep index.html, content.js, and images/ together.

Tip: the editor is local and does not automatically save edits to your website. Do not publish editor.html if you prefer keeping the editing interface private. It contains no passwords or private access.
